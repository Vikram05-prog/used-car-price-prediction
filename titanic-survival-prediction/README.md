# Titanic Survival Prediction (Google Colab)

A beginner-friendly classification project built with pandas, matplotlib, seaborn, and scikit-learn.

## Concepts covered
- CSV loading and exploratory data analysis (EDA)
- Missing-value inspection
- Numerical imputation with `KNNImputer`
- Categorical imputation with the most frequent value
- One-hot encoding
- Train-test split
- `ColumnTransformer` and `Pipeline`
- Logistic regression
- Accuracy, confusion matrix, and classification report

## Dataset
The notebook downloads the Titanic CSV from:
https://github.com/datasciencedojo/datasets

## Run in Google Colab
1. Open https://colab.research.google.com/
2. Select **File → Upload notebook**.
3. Upload `Titanic_Survival_Prediction_Colab.ipynb`.
4. Run the cells from top to bottom.

No separate dataset upload is required. Interview questions are intentionally not included in the project files.
